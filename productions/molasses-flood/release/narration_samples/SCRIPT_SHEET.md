# Script sheet — six sample lines (Hindi)

Read **exactly** the approved text. The "say it as" column is how the pipeline expands numbers;
a narrator should read numbers naturally in Hindi (it does not have to match word for word, but the
values must). Durations are the scratch voice's, for orientation only — read at a natural pace.
